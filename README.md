# Teen-Mental-Heath-Analysis
## Project Overview
This project analyzes teen mental health data using data science and machine learning techniques.  
The project includes:  
* Dataset understanding
* Data visualization
* Predictive modeling
## Dataset Information
The dataset contains 1200 records and 16 features related to:  
* sleep habits
* social media usage
* academic performance
* stress and anxiety levels
* depression indicators
## Technologies Used
* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
## Machine Learning
A Random Forest classifier was implemented to predict depression labels using behavioral and lifestyle-related features.
